# Compliance Matrix — By Product Category

Regulatory and certification requirements for Ismokraft products sold on Amazon India and Shopify India.

## Universal Requirements (All Products)

| Requirement | Applicability | Status Check |
|---|---|---|
| Legal Metrology (MRP sticker) | All packaged goods sold in India | MRP, net quantity, manufacturer address, date of manufacture |
| Country of Origin labeling | All products on Amazon India | "Made in India" on product and listing |
| GST compliance | All sales | GSTIN on invoices, correct HSN code |
| FSSAI — NOT required | Wood/decor products are not food items | Only applies if product contacts food (cutting boards, kitchen utensils) |

## Category-Specific Requirements

### Decorative / Gift Items (Zone 2, 3, 4)
| Requirement | When Required | Notes |
|---|---|---|
| BIS certification | NOT required for decorative wood items | Required only for electrical, toys, or specific regulated categories |
| Choking hazard warning | If any component < 3cm and marketed for all ages | Add warning label |
| Lead-free finish certification | If painted with colors | Vendor must provide test report |

### Kitchen / Food-Contact Items (Zone 3 — specific subcategories)
| Requirement | When Required | Notes |
|---|---|---|
| FSSAI license | If product contacts food | Vendor must hold FSSAI, or Ismokraft must obtain |
| Food-safe finish | All food-contact surfaces | No lacquer — use food-grade mineral oil or beeswax only |
| BIS IS 15495 | Wooden utensils | Test report required |
### Workspace Products (Zone 1)
| Requirement | When Required | Notes |
|---|---|---|
| BIS certification | NOT required for desk organizers, pen holders | Required if electronic component (e.g., wireless charger) |
| RoHS compliance | Only if contains electronic components | Vendor provides certificate |

### Jewelry / Accessories Storage (Zone 5)
| Requirement | When Required | Notes |
|---|---|---|
| No specific certification | Standard category | MRP + COO labeling sufficient |
| Fabric lining safety | If velvet/fabric lining used | Non-toxic adhesive, no loose fibers |

## Amazon India Specific

| Requirement | Details |
|---|---|
| GTIN/EAN barcode | Required for all FBA listings |
| Packaging integrity | Must survive 1m drop test (Amazon packaging guideline) |
| Hazmat classification | Wood products = non-hazmat (standard handling) |
| Category approval | Handmade category requires approval; Home & Kitchen is open |

## Export Compliance (if selling on Amazon US/Europe)

| Requirement | Details |
|---|---|
| Lacey Act (US) | Wood species must not be on restricted list |
| EUTR (Europe) | Proof of legal sourcing for wood |
| CE marking | NOT required for unregulated decorative items |
| California Prop 65 | Warning label if finish contains listed chemicals |
| CPSIA | Only if marketed for children under 12 |

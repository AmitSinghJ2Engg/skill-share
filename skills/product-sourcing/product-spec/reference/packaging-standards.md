# Packaging Standards

FBA packaging tiers and Shopify fulfillment specs for Ismokraft products.

## Amazon FBA Size Tiers (India)

| Tier | Max Dimensions (L+W+H) | Max Weight | Fee Impact |
|---|---|---|---|
| Standard — Small | ≤ 40cm longest side, ≤ 22cm+16cm others | ≤ 500g | Lowest handling fee |
| Standard — Medium | ≤ 50cm longest side | ≤ 2kg | Standard handling fee |
| Standard — Large | ≤ 80cm longest side | ≤ 5kg | Higher handling fee |
| Oversize | > 80cm any side or > 5kg | ≤ 22kg | Significant fee premium |

**Design rule:** Target Standard-Medium or smaller. Every cm and gram beyond Standard-Small adds fee. Packaging should minimize void space.

## Ismokraft Packaging Tiers

### Tier 1 — Gift-Ready (Zone 2, 4 products)
- Inner: Acid-free tissue paper wrap
- Insert: Branded card + care instruction card
- Box: Rigid gift box with magnetic closure OR corrugated with branded sleeve
- Estimated cost: ₹40–80/unit

### Tier 2 — Premium Standard (Zone 1, 3, 5 products)
- Inner: Bubble wrap or foam corner protectors
- Insert: Care instruction card
- Box: Corrugated box with brand sticker
- Estimated cost: ₹25–45/unit

### Tier 3 — Economy (budget SKUs, bundles)- Inner: Shrink wrap or poly bag
- Insert: None
- Box: Brown corrugated mailer
- Estimated cost: ₹15–25/unit

## Box Dimension Calculation

1. Product dimensions + 2cm padding each side = inner box dimensions
2. Inner box + 0.5cm corrugation thickness each side = outer box dimensions
3. Calculate volumetric weight: (L × W × H in cm) / 5000 = volumetric kg
4. FBA uses higher of actual weight and volumetric weight

## Labeling Placement

| Label | Placement | Size |
|---|---|---|
| FNSKU barcode (FBA) | Outside of box, scannable | Min 2.5cm × 5cm |
| MRP sticker | Product surface or inner box | As per Legal Metrology rules |
| Brand label | Product surface (engraved/printed/sticker) | Per brand guidelines |
| Care instructions | Inside box on card | Standard card size |
| "Fragile" marking | Outside box if applicable | Standard symbol |

## Shopify Fulfillment (Self-Shipped)

- Use same packaging tiers as above
- Add shipping label pocket or clear pouch on outside
- Include return slip inside box
- Tamper-evident tape for COD orders
